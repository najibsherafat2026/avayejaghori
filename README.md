# آوای جاغوری | Avaye Jaghori

**صدای فرهنگ، دانش، ایمان و هویت**

An independent Persian (Dari) media and knowledge hub for Islamic knowledge, the history and culture of Jaghori and the Hazara people, education and research, a digital library and multimedia.

## What exists today
- Home page with the hero, featured and latest content, category hub, news, religious and history columns, new books, videos and podcasts, popular posts, authors, and a newsletter section.
- An article archive with Persian-aware search (it treats ی/ي and ک/ك as the same letter) and filters by category, content type and sort order.
- An article page with a table of contents, sources, tags, share, print and a comment form.
- A digital library with category filters, search, book details and related books.
- An About page with the mission, editorial policy and contact details.
- A full right-to-left Persian interface that works on phones and desktops, with Shamsi, Hijri and Gregorian dates.

All content is sample data, labelled «نمونه».

## Tech
TanStack Start (React 19), Tailwind CSS 4, shadcn/ui, Vazirmatn font, Netlify Image CDN, deployed on Netlify.

## Run locally
```bash
pnpm install
netlify dev   # or: pnpm dev
```
